Deep neural networks (DNNs) are widely recognized as state-of-the-art for a wide range of problems such as natural language processing, computer vision, and software engineering. There are two primary types of DNNs: (i) networks that take fixed-size input, i.e., inputs with predefined sizes, such as feed-forward neural networks (FNNs) and convolutional neural networks (CNNs), and (ii) networks that take inputs with varying sizes and structures, such as graph neural networks (GNNs).

GNNs are a powerful tool for modeling complex data structures. Many problems can be modeled with graphs in a straightforward way, from detecting fake users and fake news and doing recommendations on social media, to mimicking classic combinatorial optimization and detecting faults in software. In these representations a graph can have varying numbers of nodes and edges, for example a person in a social network can have varying numbers of friends, or a molecule can have varying numbers of atoms, etc. CNNs and FNNs are not designed for data structures that vary like this, but GNNs can handle these varying structures naturally using the message-passing mechanism. However, the message-passing mechanism is complex, and this makes it difficult to debug GNNs, e.g., to assess how robust GNNs are against adversarial attacks or to detect backdoor behaviors. For debugging GNNs, existing explainable AI techniques provide heatmaps that help human experts debug GNNs manually. As far as we know, there is no technique that supports automated debugging of GNNs.

There are, however, recent works on automated debugging of CNNs and FNNs that infer formal properties to interpret and assess the performance of deep neural networks. These techniques take as input a DNN together with a set of input data of fixed size and fixed structure, and then they infer a set of formal properties, which are logical constraints that capture the relationships between the input and output of the DNN. These techniques are powerful, but they cannot handle inputs with varying sizes and structures such as graphs, where the number of nodes and edges and the connections between them can change dynamically. So it is very challenging to adopt these techniques for automated debugging of GNNs.

In this work we introduce GNN-Infer, which is the first automatic property inference technique for GNNs, to facilitate automated debugging of GNNs. GNN-Infer handles the challenge of dynamic input graph structures in GNN in three steps, and each of them is a novel contribution. First, we select a set of representative input structures to analyze. Second, we infer the GNN's properties on each of the representative structures. Finally, we generalize these properties to varying structures that contain the representative structures. To do this, GNN-Infer first mines the most frequent influential structures, which are structures that appear frequently in the dataset and contribute significantly to the GNN's prediction. These structures are more likely to capture the GNN's behavior, as prior works have shown, so they are considered representative input structures. Next, for each influential structure S that is input to a GNN model \mathcal{M}, GNN-Infer converts the pair \langle\mathcal{M},S\rangle into an equivalent FNN model \mathcal{M}_{F}. We formally prove that our conversion algorithm is sound, i.e., \mathcal{M}_{F} is indeed equivalent to \langle\mathcal{M},S\rangle, and also complete, i.e., for any \langle\mathcal{M},S\rangle there always exists an equivalent \mathcal{M}_{F}. This lets us use an existing property inference technique for FNNs, namely PROPHECY, to infer a set of properties \{S_{P}\}. These inferred properties \{S_{P}\} are then treated as the properties of the original GNN \mathcal{M} on the given structure S.

The inferred properties \{S_{P}\} are still specific to the frequent influential structures: each property S_{P} has an input condition that the input graph must have exactly the structure S. GNN-Infer then generalizes these properties to any input graph that contains the influential structures, by relaxing each S_{P} into a likely property S_{LP}, where the input condition is that the input graph must contain the structure S. When the input condition is relaxed, the likely property S_{LP} might lose precision. To improve the precision of these likely properties, GNN-Infer trains a model (either a decision tree or linear regression) that estimates how much the GNN output deviates from the inferred properties on a given full input graph. The predictions of this model help GNN-Infer get more precise properties that hold on the full input graph.

We evaluate the correctness and applicability of GNN-Infer on both synthetic and popular real-world datasets. To assess the correctness, we construct a synthetic benchmark of reference GNNs and corresponding ground truth properties: the benchmark contains reference and trained GNNs that mimic the classic breadth-first search (BFS), depth-first search (DFS) and Bellman-Ford (B-F) algorithms. Manual assessments show that out of 13 ground-truth properties, GNN-Infer re-discovered 8 correct properties, and it identified highly confident properties that approximate the remaining ground-truth properties. As an application of GNN-Infer, we use the inferred properties to detect and defend against the state-of-the-art backdoor attack technique on GNNs, namely UGBA. The experiments show that the inferred properties of GNN-Infer can be used to improve the defense against the state-of-the-art backdoor attack method UGBA by up to 30 times compared to existing baseline defense methods. In summary, our contributions are:

- We propose GNN-Infer, which automatically infers properties of GNNs by analyzing and generalizing the behaviors of GNNs on representative structures.

- We give an algorithm that converts a GNN with a given input structure into an equivalent FNN. We formally prove the algorithm is sound and complete, which lets us use existing DNN analysis tools to infer properties of the GNN.

- We construct a set of benchmarks with GNNs on classic traversal and shortest path algorithms to evaluate GNN-Infer, and we show that GNN-Infer can infer correct properties.

- Finally, we show that GNN-Infer can be used to improve the backdoor defense against state-of-the-art backdoor attack techniques on graph neural networks by up to 30 times compared to existing techniques, namely homophily-based pruning and isolation.

Two primary types of DNNs are (i) networks that take fixed-size input, i.e., inputs with predefined sizes, such as feed-forward neural networks (FNNs) and convolutional neural networks (CNNs) [8,9,10], and (ii) networks that take inputs with varying sizes and structures, such as graph neural networks (GNNs) [11,12,13,14].

GNNs are a powerful tool for modeling complex data structures. Problems ranging from detecting fake users [15], fake news [16], and performing recommendations [17,18] on social media to mimicking classic combinatorial optimization [19,20] and detecting faults in software [21,22,23] can be straightforwardly modeled using graphs. In these representations, a graph can have varying numbers of nodes and edges; for example, a person in a social network can have varying numbers of friends, or a molecule can have varying numbers of atoms, etc [24]. While CNNs and FNNs are not designed for such varying data structures, GNNs can naturally handle them using the message-passing mechanism [11]. However, the complexity of the message-passing mechanism makes it difficult to debug GNNs, e.g., to assess the robustness of GNNs against adversarial attacks [25,26,27,28,29] or to detect backdoor behaviors [30,31,32]. To tackle GNN debugging, existing explainable AI techniques provide heatmaps that help human experts manually debug GNNs [33,34,35]. To the best of our knowledge, no technique exists that supports automated debugging of GNNs.

There are, however, recent works on automated debugging of CNNs and FNNs that infer formal properties to interpret and assess deep neural network performance [36,37,38]. These techniques take as input a DNN along with a set of fixed-size and fixed-structure input data, and then infer a set of formal properties, i.e., logical constraints that capture the relationships between the input and output of the DNN. Despite being powerful, these techniques cannot handle inputs with varying sizes and structures such as graphs, wherein the number of nodes and edges and the connections between them can change dynamically. It is thus significantly challenging to adopt these techniques for automated debugging of GNNs.

In this work, we introduce GNN-Infer, the first automatic property inference technique for GNNs, to facilitate automated debugging of GNNs. GNN-Infer tackles the challenge of dynamic input graph structures in GNNs in three steps, each of which is a novel contribution. First, we select a set of representative input structures to analyze. Second, we infer the GNN's properties on each of the representative structures. Finally, we generalize these properties to varying structures that contain the representative structures. To achieve this, GNN-Infer first mines the most frequent influential structures, which appear frequently in the dataset and contribute significantly towards the GNN's prediction. These structures are more likely to capture the GNN's behavior, as shown in prior works [39,40], and are thus considered representative input structures. Next, for each influential structure S as input to a GNN model \mathcal{M}, GNN-Infer converts the pair \langle\mathcal{M},S\rangle into an equivalent FNN model \mathcal{M}_{F}. We formally prove that our conversion algorithm is both sound, i.e., \mathcal{M}_{F} is indeed equivalent to \langle\mathcal{M},S\rangle, and complete, i.e., given any \langle\mathcal{M},S\rangle, there always exists an equivalent \mathcal{M}_{F}. GNN-Infer then generalizes these properties to any input graph containing the influential structures by relaxing each S_{P} into a likely property S_{LP}, whose imposed input condition is that the input graph must contain the structure S. The model's predictions help GNN-Infer obtain more precise properties that hold on the full input graph.
