<details><summary><b>Step 2 — rough_draft</b> (964 words)</summary>

````text
Large pre-trained vision-language models (VLMs) get remarkable accuracy without any task-specific training, but they still need to be adapted to get optimal performance. Prompt-tuning is one way to efficiently improve VLM performance on downstream tasks, by learning the inputs to the model. Learning prompts with a few labeled examples can give big improvements, but a broader range of learning settings, like semi-supervised, transductive zero-shot and unsupervised learning, are still underexplored. All of these settings have access to unlabeled data, and because VLMs have versatile zero-shot classification abilities, pseudolabeling is a natural way to use that data. In this paper we look at how out-of-the-box pseudolabels assigned by CLIP can help to improve CLIP's own performance. For this we do an extensive exploration of learning scenarios, where we vary the prompt modalities, the learning paradigms and the training strategies. We show empirical evidence that iterative prompt-training strategies that use CLIP-based pseudolabels are effective regardless of the learning paradigm and the prompt modality, and that they give significant improvements in CLIP's image classification performance in different settings.

Pseudolabels are heuristic labels that a model assigns to unlabeled data, which are then used to train the model further. Training with pseudolabels successfully depends on two things: how good the labels are, and how they are used in training. For the first one, conventional methods give labels to the instances with high-confidence predictions. For pseudolabeling with CLIP, Huang et al. select the most confident samples for each class, which mitigates CLIP's bias and miscalibration (see Section 3). We use this approach to assign pseudolabels, and we deal with the second point by exploring how to make the best use of them. We design a broad space of analysis with three dimensions: prompt modalities, which are the model inputs we learn; learning paradigms, which define the data we have available; and training strategies, which describe the process used to optimize performance (Figure 1).

Research on prompt tuning has shown that training strategies for learning prompts in one modality can be transferred to learning prompts in another modality. For example, Visual Prompt Tuning was originally designed to fine-tune large vision models effectively, but it can be adapted to fine-tune CLIP efficiently with the same training strategy as standard textual prompt tuning. On the other hand, different learning paradigms with limited labeled data usually need distinct approaches that are tailored to get information out of the data that is available. But we observe that this changes when we use the pseudolabels generated by the VLM. Conventional pseudolabeling approaches bootstrap off labeled data and are used as semi-supervised learning techniques, but VLMs can generate pseudolabels in any learning setting. This is a significant advantage, because it expands the scope of pseudolabeling beyond semi-supervised learning and makes it a promising approach for other settings too, like transductive zero-shot and unsupervised learning. If we use CLIP-based pseudolabels as a source of supervision, we can see all these settings as optimizing the same loss function, which is just a weighted sum of the errors on labeled data, if there is any, and on pseudolabeled data. Since the different settings can be written as the same problem, we can propose training strategies, i.e., ways of using the pseudolabels, that work for all of them.

Because the training strategies are standardized across prompt modalities and learning settings, we can run experiments on different applications of pseudolabels for various combinations of prompt modalities, learning paradigms and training strategies, as shown in Figure 1. As far as we know, only one possible path has been explored so far, which is fine-tuning textual prompts in an unsupervised learning setting with a few pseudolabels. Instead of relying on a fixed set of pseudolabels, we propose iterative training techniques that keep refining and expanding the pool of pseudolabeled data that is used in training. With each iteration CLIP's pseudolabeling ability gets better, so we can extend the set of pseudolabeled data and still keep the high quality of the initial pseudolabels.

We run experiments on six tasks where CLIP has been observed to underperform, for example satellite-image classification, flower-species identification and texture-image recognition, among others. Our findings show that iterative approaches fine-tune prompts effectively no matter what the modality and the learning paradigm are. Recent studies have identified the “Matthew effect” as a possible issue for semi-supervised models that use pseudolabels. Because of this effect, models do well on classes with accurate pseudolabels but badly on the ones with inaccurate pseudolabels, which reinforces the model's original bias towards certain classes. Our analysis shows that using pseudolabels generated by CLIP for prompt-tuning with iterative strategies not only improves CLIP's overall performance but also corrects its natural bias towards certain classes.

The main takeaways of our work are:

- General purpose zero-shot learners can be used as general purpose pseudolabelers, and this opens the opportunity to develop training strategies that use pseudolabeled data beyond semi-supervised learning. Different learning paradigms, like semi-supervised, transductive zero-shot and unsupervised learning, can all be seen as special cases of a single objective function, by using pseudolabels as a source of supervision.

- Simple iterative training strategies that refine pseudolabels are very effective for limited-label prompt tuning. Regardless of the prompt modality and the learning setting, these strategies improve CLIP on average by 19.5 points in semi-supervised learning, 28.4 in transductive zero-shot learning and 15.2 in unsupervised learning.

- Prompts learned with iterative strategies help to mitigate the "rich get richer, poor get poorer" effect that is seen in semi-supervised approaches using pseudolabels. The quality of the pseudolabels gets redistributed across the classes, and we see a “Robin Hood effect” where the accuracy of the extremely rich classes stays the same or goes down, while the poorer classes get richer, which leads to a more equitable distribution of per-class accuracy.
````

````text
Large pre-trained vision-language models (VLMs) [1,2,3] achieve remarkable accuracy without task-specific training but still require adaptation for optimal performance. Prompt-tuning [4,5] is an approach to efficiently enhance VLMs performance on downstream tasks by learning inputs to the model. While learning prompts with a few labeled data can yield significant improvements [6,7], a broader range of learning settings such as semi-supervised, transductive zero-shot, and unsupervised learning are still underexplored. All of these settings share access to unlabeled data, and the versatile zero-shot classification abilities of VLMs make pseudolabeling a natural approach to leveraging it. This paper investigates how the use of out-of-the-box pseudolabels assigned by CLIP can contribute to improving CLIP’s own performance. To this end, we conduct an extensive exploration of learning scenarios by varying prompt modalities, learning paradigms, and training strategies. We present empirical evidence showcasing the effectiveness of iterative prompt-training strategies that leverage CLIP-based pseudolabels, regardless of learning paradigms and prompt modalities, resulting in significant improvements in CLIP’s image classification performance across different settings.

Pseudolabels are heuristic labels assigned by a model to unlabeled data, which are leveraged to further train the model [8]. Successful training with pseudolabels relies on two factors: the quality of the labels and how they are used during training. To address the first, conventional methods assign labels to instances with high-confidence predictions [9]. For pseudolabeling using CLIP, Huang et al. propose to select the most confident samples for each class [10], mitigating CLIP’s bias [11] and miscalibration [12] (see Section 3). To assign pseudolabels, we rely on this approach and address the second point by exploring how to make the best use of them. We design a broad space of analysis considering three dimensions: prompt modalities, which are the model inputs we learn; learning paradigms, which define the data we have available; and training strategies, which describe the process used to optimize performance (Figure 1).

Research on prompt tuning has demonstrated that training strategies used for learning prompts in one modality can be transferred to learning prompts in a different modality. For instance, Visual Prompt Tuning [5] was originally designed to effectively fine-tune large vision models but can be adapted to efficiently fine-tune CLIP using the same training strategy as standard textual prompt tuning [6,13,14]. On the contrary, different learning paradigms with limited labeled data typically require distinct approaches specifically tailored to extract information from the available data [15,16]. However, we observe that this changes by using VLM’s generated pseudolabels. Unlike conventional pseudolabeling approaches that bootstrap off labeled data and are used as semi-supervised learning techniques [9,17,18], VLMs can generate pseudolabels in any learning setting. This offers a significant advantage, expanding the scope of pseudolabeling beyond semi-supervised learning, and making it a promising approach for other settings, such as transductive zero-shot and unsupervised learning. By using CLIP-based pseudolabels as a source of supervision, we can view these settings as optimizing the same loss function, which is simply a weighted sum of the errors on labeled data, if available, and pseudolabeled data. Given that we can express different settings as the same problem, we can propose training strategies, i.e., the way of using pseudolabels, that suit them all.

By standardizing the training strategies across various prompt modalities and learning settings, we can conduct experiments on different applications of pseudolabels for various combinations of prompt modalities, learning paradigms, and training strategies, as illustrated in Figure 1. To the best of our knowledge, only one potential path has been explored thus far; specifically, fine-tuning textual prompts in an unsupervised learning context using a few pseudolabels [10]. Rather than relying on a fixed set of pseudolabels, we propose iterative training techniques that allow for the ongoing refinement and expansion of the pool of pseudolabeled data used during training. With each iteration, we progressively enhance CLIP’s pseudolabeling ability, allowing us to extend the set of pseudolabeled data while maintaining the high quality of the initial pseudolabels.

We conduct experiments on six tasks where CLIP has been observed to underperform [1], such as satellite-image classification, flower-species identification, and texture-image recognition, among others. Our findings reveal that iterative approaches effectively fine-tune prompts irrespective of their modality and learning paradigms. Recent studies have identified the “Matthew effect” as a potential issue for semi-supervised models that use pseudolabels [19,11]. This phenomenon causes models to perform well on classes with accurate pseudolabels but poorly on those with inaccurate ones, thereby reinforcing the model’s original bias towards certain classes. Our analysis reveals that using pseudolabels generated by CLIP for prompt-tuning with iterative strategies not only improves CLIP’s overall performance but also corrects its natural bias towards certain classes.

We summarize the main takeaways of our work:

- • General purpose zero-shot learners used as general purpose pseudolabelers open the opportunity to develop training strategies that leverage pseudolabeled data beyond semi-supervised learning. We point out that different learning paradigms, such as semi-supervised, transductive zero-shot, and unsupervised learning, can be all considered as special cases of a single objective function, by using pseudolabels as a source of supervision.

- • We demonstrate that simple iterative training strategies for refining pseudolabels are highly effective approaches for limited-label prompt tuning. In fact, regardless of the prompt modality and learning setting, these strategies improve CLIP, by on average 19.5 points in semi-supervised learning, 28.4 in transductive zero-shot learning, and 15.2 in unsupervised learning.

- • We show that prompts learned with iterative strategies help mitigate the "rich get richer, poor get poorer" effect observed in semi-supervised approaches leveraging pseudolabels. By redistributing the quality of pseudolabels across different classes, we observe a “Robin Hood effect” where the extremely rich classes’ accuracy stays the same or decreases, while poorer classes get richer, leading to a more equitable distribution of per-class accuracy.
````
