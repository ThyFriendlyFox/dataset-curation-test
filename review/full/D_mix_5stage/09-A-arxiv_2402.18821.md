<details><summary><b>Step 2 — rough_draft</b> (648 words)</summary>

````text
Object detection is a fundamental research area in computer vision, and it is now widely used in security, autonomous driving, the medical field and other areas.

Existing object detection methods are trained on closed-set datasets that have a fixed number of categories. Most of the research is about improving detection performance on closed-set datasets. In closed-set scenarios the object detectors are evaluated on a test set with the same categories as the training set. But in the real world, object detectors see both known objects and possible unknown objects which never appeared or were annotated in the training set. After they are trained, they do not know about any objects that they did not see during training. They either treat the unknown objects as background or misclassify them as known categories. Humans on the other hand can perceive, discover, and recognize unknown novel objects. So the Novel Category Discovery problem, which aims to detect known objects and also discover novel categories unsupervisedly, has attracted a lot of attention.

Most NCD methods first do pre-training on labeled sets and then work on unlabeled data. For example, one method adds partial information from known classes to unknown classes, pretending that some parts are unlabeled, and then it runs clustering algorithms in the expansion phase for model inference. Handling unlabeled data during pre-training like this makes the model learn from unknown data. This can improve the model's ability to discover unknown data, but the model should not have prior knowledge of the unlabeled dataset, so it does not apply to real-world scenarios. Another method uses all data, labeled and unlabeled, for pre-training. But such methods have to repeat the pre-training on all data every time the unlabeled set is modified, and this makes training expensive. Most NCD methods have three steps. First, the object detector is pre-trained on a closed set. Second, potential unknown new objects are localized and discovered. Last, the discovered objects are put into new categories by clustering. This approach is effective, but most methods only use known objects and categories for pre-training and localization, and this may introduce bias. These methods use detection heads for closed sets, which may give biased feature representations. In the same way, training RPNs only on labeled closed-set objects may also lead to biased localization.

To deal with these issues, we propose debiased NCD methods that reduce bias in both feature representation and object localization. From the localization side, we introduce a self-supervised contrastive learning method. With this method the model learns similar features for similar data instances and it can tell unknown class objects apart from known class objects. For feature representation, we propose a dual RPN strategy that detects target objects in the image at the same time. One RPN is class-aware, and it aims to get accurate localization information for known classes. The other RPN is class-agnostic, and in it the classification loss is replaced with IOU regression to locate unlabeled target objects. The bounding boxes we get from both detectors are selected as reliable confidence intervals, and this improves performance for both known and unknown classes.

Finally, we do extensive experiments on NCDL benchmarks and show that our debiased region mining method is significantly better than previous methods, and it is a new state-of-the-art.

Our contributions are:

- We revisit novel category discovery in an open world and look into the bias problem in existing methods.

- We propose to use dual object detectors together to get a good area proposal, which can find all target objects in the image effectively and locate them better.

- We design a Semi-Supervised Instance-level Contrastive Learning method to get better image representations than before and to make the model rely on unlabeled image information to learn image features.

- We did a large number of experiments based on this approach, and they show our method is better than other baseline methods.
````

````text
Object detection [1,2,3] technology is a fundamental research area of computer vision and is now widely used in security [4], autonomous driving [5], medical [6] field and other areas.

Existing object detection methods are trained on closed-set datasets with a fixed number of categories. The majority of research focuses on improving detection performance on closed-set datasets. In closed-set datasets scenarios, object detectors are evaluated on a test set that contains the same set of categories as the training set. However, in the in real-world scenario, object detectors are faced with both known objects and potential unknown objects that have never appeared or been annotated in the training set. Once trained, they are unaware of any objects that they have not seen during training. They either treat the unknown objects as background or misclassify them as known categories. By contrast, humans have the capability of perceiving, discovering, and recognizing unknown novel objects. Therefore, the Novel Category Discovery problem, which aims to not only detect known objects, but also discover novel categories unsupervisedly, has attracted much attention

Most NCD methods involve a pre-training step on labeled sets and then perform on unlabeled data. For example, [7] adds partial information from known classes to unknown classes, pretending that some parts are unlabeled, and then runs clustering algorithms in the expansion phase for model inference. This approach of handling unlabeled data during pre-training will cause the model to learn from unknown data. While this can improve the model’s ability to discover unknown data, the model should not have prior knowledge of the unlabeled dataset, which is not applicable in real-world scenarios. [8] utilizes all data, including labeled and unlabeled data, for pre-training. However, such methods require repetitive pre-training on all data after modifying the unlabeled set, resulting in expensive training costs. Most NCD methods [9,7] have three steps. First, the object detector is pre-trained on a closed set. Second, localize and discover potential unknown new objects. Finally, the discovered objects are categorized into new categories by clustering. While this approach proves its effectiveness, most methods only utilize known objects and categories for pre-training and localization, which may introduce bias. Such methods use detection heads for closed sets which may introduce biased feature representations. Similarly, training RPNs only on labeled closed-set objects may also lead to biased localization.

To address the aforementioned issues, we propose debiased NCD methods to mitigate bias in both feature representation and object localization. Specifically, from the localization perspective, we introduce a self-supervised contrastive learning method. This method enables the model to learn similar features for similar data instances and differentiate unknown class objects from known class objects. Regarding feature representation, we propose dual RPN strategy to simultaneously detect target objects in the image. One RPN is designed to be class-aware, which aims to obtain accurate localization information for known classes. The other RPN is designed to be class-agnostic, where the classification loss is replaced with IOU regression to locate unlabeled target objects. The resulting bounding boxes from both detectors are selected as reliable confidence intervals, leading to improved performance for both known and unknown classes.

Finally, we conduct extensive experiments on NCDL benchmarks and demonstrate that the proposed debiased region mining method outperforms previous methods significantly, establishing a new state-of-the-art.

Our contribution can be summarized as follows:

- \bullet We revisit the problem of novel category discovery in an open world and investigate the bias problem in existing methods.

- \bullet We propose using dual object detectors together to obtain a good area proposal that can effectively find all target objects in the image and locate them better.

- \bullet We design a Semi-Supervised Instance-level Contrastive Learning method to obtain image representations better than before and make the model rely on unlabeled image information to learn image features.

- \bullet Based on this approach we have conducted a large number of experiments, which show that our method outperforms other baseline methods.
````
