<details><summary><b>Step 2 — rough_draft</b> (372 words)</summary>

````text
Machine learning has advanced a lot in recent years, and state of the art models can now do impressive tasks in a wide range of technical domains. But the standard way machine learning is done is a lot less flexible than the learning we see in animals in nature. Biological neural systems learn continually and in uncontrolled environments. Artificial neural networks on the other hand are trained under a closed-world assumption, they are trained on a fixed corpus of training data, validated on reserved data that comes from the same data distribution, and then deployed to do roughly the same task. Once deployed, these models can see inputs that are dissimilar to the in-distribution (ID) data that they were trained and validated on, and when they encounter this out-of-distribution (OOD) data their behavior can be unpredictable.

It is still a challenge to use artificial neural networks in open world situations where they may see out-of-distribution data. Out-of-distribution detection is the task of identifying when a sample is not drawn from the training data distribution. This matters especially in safety critical applications like autonomous vehicles, because the statistical assurances on model performance that the validation dataset gives no longer apply.

In this work we revisit feature density estimation (FDE) using normalizing flows for out-of-distribution detection in image classification. Prior work has said that normalizing flows are not effective for OOD detection when the density estimation is done in pixel space, and density estimation in the feature space of pretrained models has been discussed but it has not been thoroughly investigated. We show that if we do density estimation in the feature space of a pretrained image classification backbone model, normalize the feature representations, and under-train the normalizing flow, we can get competitive results on both small and large datasets. The method is fully unsupervised and it does not need any exposure to OOD training data, which avoids researcher bias that comes from a specific definition of the OOD data. Also, the method is post-hoc so it can be applied to any pretrained classification model. It only requires training a lightweight normalizing flow model for a single epoch to do the feature-space density estimation for out-of-distribution detection, so it is a broadly applicable technique.
````

<details><summary><b>Step 4 — final</b> (461 words)</summary>

````text
Machine learning has rapidly advanced in recent years, with state of the art models performing impressive tasks in a wide range of technical domains. However the standard workflow in machine learning is significantly less flexible than learning observed in animals in nature. While biological neural systems continually learn in uncontrolled environments, artificial neural networks are instead trained with a closed-world assumption [1] on a fixed corpus of training data, validated against a set of reserved data drawn from the same data distribution, and then deployed to perform roughly the same task. When deployed, these models can be exposed to inputs that are dissimilar to the in-distribution (ID) data they were trained and validated on, potentially leading to unpredictable behavior when encountering this out-of-distribution (OOD) data.

Addressing how artificial neural networks can be used in open world situations where they may be exposed to out-of-distribution data remains a challenge. Out-of-distribution detection is the task of identifying when a sample is not drawn from the training data distribution. This is especially important in safety critical applications such as autonomous vehicles; the statistical assurances on model performance provided by the validation dataset are no longer applicable.

In this work, we revisit using feature density estimation (FDE) via normalizing flows for out-of-distribution detection in image classification. Prior works assert that normalizing flows are not effective for OOD detection when performing density estimation in pixel space [2], and density estimation in the feature space of pretrained models has been discussed but not thoroughly investigated [3]. We demonstrate that by performing density estimation in the feature space of a pretrained image classification backbone model, normalizing the feature representations, and under-training the normalizing flow we are able to achieve competitive results on both small and large datasets. The proposed method has the advantages of being fully unsupervised and requires no exposure to OOD training data, avoiding researcher bias from a specific definition of the OOD data. Finally, this is a post-hoc method that can be applied to any pretrained classification model, and it requires training a lightweight normalizing flow model for only a single epoch to perform the feature-space density estimation for out-of-distribution detection, making it a broadly applicable technique.
````
