Query expansion is a technique that has been used in information retrieval for a long time, over half a century. The idea is to add more terms to the query so that the retrieval is more accurate. The conventional methods, for example RM3, use pseudo relevance feedback (PRF), which means they take the documents retrieved for the original query and select terms from them to use as expansions. More recently large language models (LLMs) have shown that they are effective at generating expansion terms for retrieval, and this is called generative query expansion. But both kinds of methods, or combinations of them, are mostly considered for improving the recall and precision of first-stage retrievers. How they influence the generalization of second-stage, cross-encoder rerankers is still under-explored.

This is an interesting problem because the additional terms usually have more information about the query, but they are rarely used in cross-encoder ranking. A recent study looked at generative query expansion for different retrievers and rankers. It found that weaker models benefit more from the expansions, while stronger rankers get hurt by them most of the time. This is counter-intuitive, and it means the current expansion methods need to be examined further, and also whether there is a way to improve the results of strong rankers with query expansion. The results are in Table 1 and they are consistent with the recent study: the nDCG@10 scores of both rankers on TREC DL 2019/2020 and BEIR get worse when we use either PRF or LLMs. Sections 4 and 5 have more results.

We think there are two important steps for using query expansion successfully in cross-encoder rankers, and existing work that focuses on retrievers does not explore them well. These are high-quality keyword generation and query modification that is minimally disruptive. The first one is needed because cross-encoder rankers mostly try to improve precision-related metrics such as nDCG@10, and these metrics are sensitive to noisy keywords. Retrievers care more about recall, and there some low-quality expanded keywords do not matter as much. So strong rankers like RankT5 need the generation to be of higher quality. The second one is needed because cross-encoder rankers are heavily based on token interactions. This makes them sensitive to distributional shift in the queries (for example the number of tokens, or input formats), more than retrievers are. So inserting documents in a query might not be a good idea for them.

In our experiments the most effective way we found is to first use an LLM to generate short, high-quality keywords through a reasoning chain. Then we run this process multiple times, following self-consistency, which filters out the noisy keywords, and we select the top-k candidates, so that the generated keywords are of good quality. To deal with the distributional shift in the query, we insert each keyword with the query independently and then combine the ranking results with reciprocal rank weighting. With this pipeline the nDCG@10 improves over the baselines for cross-encoder rankers like RankT5 on both BEIR and TREC DL 2019/2020. The other baselines, which were found to be effective for retrievers, do not manage to improve these strong rankers. Our study is preliminary, but it is a novel research foundation for researchers who want to explore query expansion for cross-encoder rankers.

In our experiments, we find that the most effective way is to first use an LLM to generate high-quality, short keywords through a reasoning chain [11]. We then follow self-consistency [12] to run the above process multiple times to filter noisy keywords and select top-k candidates, ensuring the quality of the generated keywords. To mitigate distributional shift in query, we insert each keyword independently with the query and use reciprocal rank weighting [13] to combine the ranking results. Our pipeline manages to improve the nDCG@10 over the baselines for cross-encoder rankers such as RankT5 [8] on both BEIR and TREC DL 2019/2020, while other baselines that have been found effective for retrievers fail to improve such strong rankers. Our study provides a preliminary yet novel research foundation for researchers to explore query expansion for cross-encoder rankers.
