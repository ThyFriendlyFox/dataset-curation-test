The language distance problem is a very fundamental problem in formal language theory. The task in this problem is to compute what the minimal distance is between a given string S and any string that belongs to a formal language L. The problem was introduced by Aho and Peterson in the early 1970s, and since then it has been studied a lot. It has been studied for regular languages under Hamming and edit distances, for general context-free languages where the focus was mainly on the edit distance, and in particular for the Dyck language, which is the language of well-nested parentheses sequences.

In this work we study the online and low-distance version of the language distance problem and its complexity. Here we are given a string T of length n and we need to compute the minimal distance from every prefix of T to a formal language L (the problem definition specifies the distance and the language). We focus on the low-distance regime, which means that we assume we are given a threshold parameter k and distances that are larger than k don't need to be computed. We consider the edit distance, which is the minimum number of character insertions, deletions and substitutions needed to transform one string into the other, and also, as a preliminary step, the Hamming distance, which only allows substitutions. We study the problem for two classical languages. The first one is the language PAL of all palindromes, where a palindrome is a string that is equal to its reversed copy. The second one is the language SQ of all squares, where a square is two copies of a string concatenated. These two languages are very similar but they are also very different in nature: PAL is context-free but it is not regular, while SQ is not even context-free. The problems we consider are defined formally as follows:

k - LHD - PAL (resp. k - LHD - SQ) Input: A string T of length n and a positive integer k. Output: For each 1\leq i\leq n, report \min\{k+1,hd_{i}\}, where hd_{i} is the minimum Hamming distance between the prefix of T of length i and a string in PAL (resp. in SQ).

k - LED - PAL (resp. k - LED - SQ) Input: A string T of length n and a positive integer k. Output: For each 1\leq i\leq n, report \min\{k+1,ed_{i}\}, where ed_{i} is the minimum edit distance between the prefix of T of length i and a string in PAL (resp. in SQ).

Amir and Porat showed a randomised streaming algorithm for the k - LHD - PAL problem that uses \tilde{O}(k) space and \tilde{O}(k^{2}) time per input character. We continue this line of research. We show streaming algorithms for all four problems, and they use \poly(k,\log n) time per character and \poly(k,\log n) space. Streaming algorithms are extremely efficient, in particular the space complexities above count all the space that the algorithms use, including the space for storing information about the input. But it is important to note that streaming algorithms are randomised, so they may give incorrect results with some probability (inverse polynomial in the input size n). Because of this we also study the problems in the read-only model. In this model random access to the input is allowed and it is not counted in the space usage. In the read-only model we show deterministic algorithms for the four problems which use \poly(k,\log n) time per character and \poly(k,\log n) space, see Table 1 for a summary. We also get a side result that is of independent interest: we develop the first \poly(k,\log n) space read-only algorithms for computing k -mismatch and k -edit occurrences of a pattern in a text.

Because of the lack of space, the descriptions of the algorithms for the Language edit distance problems (k - LED - PAL and k - LED - SQ) are not in this version of the paper. They can be found in the full version.

## 1.1 Related work.

Offline model. In the classical offline model, finding all maximal substrings that are within Hamming distance k from PAL can be done in O(nk) time, which is a simple application of the kangaroo jumps technique. Porto and Barbosa showed an O(nk^{2}) solution for the edit distance. For the SQ language the best known solutions take O(nk\log k+\mathrm{output}) time for the Hamming distance and O(nk\log^{2}k+\mathrm{output}) for the edit distance.

Online model. The problems k - LHD - PAL and k - LED - PAL can be seen as a generalization of the classical online palindrome recognition problem.

Streaming algorithms for PAL and SQ. Berebrink et al. and after them Gawrychowski et al. studied how to compute the length of a maximal substring of a stream that belongs to PAL. Merkurev and Shur looked at a similar question for the SQ language.
